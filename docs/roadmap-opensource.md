# 最终目标路线：开源级强学习 Agent

> 定版目标（2026-10-31）：公开发布到 GitHub 的开源学习 Agent——
> 不是演示品。标准：陌生人 clone 下来能一键跑、能看懂架构、能参与贡献，
> 教学效果有评测数据支撑。

  这是学习目标本身，不外包、不抢跑

## 知识库扩张（范围：现电全课程）

当前课程包只覆盖“三极管放大电路”一章。扩张走既有课程包架构
（`content/*.json`，一课一包、互不干扰），顺序与口径：

1. **范围以老师课件为准**：每章以老师 PPT 的知识点与例题风格定版，
   教材（童诗白/华成英）与国家智慧教育平台大纲只作参照系，不越位
2. **每章的生产流水线固定**：知识点与先修关系 → 误区清单 → LLM 按误区码
   起草题目与干扰项 → 人工双审 → 入库 + 课程包校验（CI 已有）
3. **存量先行**：`docs/bjt-materials.md` 的 U1–U8 知识图谱是模电部分的
   现成骨架，逐单元转成知识点与诊断题

## 不变的设计红线（任何版本）

1. 掌握判定只认独立测验的证据，不认学生自述、不认对话流畅度
2. 教学决策可解释、可测试；LLM 只做判读与表达，不做流程决策
3. 没把握的内容宁可拒答，不编造公式和出处
4. 学生数据只存本地/自有服务器，密钥永不入库
