# 最终目标路线：开源级强学习 Agent

> 定版目标（2026-10-31）：公开发布到 GitHub 的开源学习 Agent——
> 不是演示品。标准：陌生人 clone 下来能一键跑、能看懂架构、能参与贡献，
> 教学效果有评测数据支撑。

## 发布前检查单（开源就绪定义）

- [x] MIT LICENSE
- [x] CI（GitHub Actions：双 Python 版本跑测试 + 课程包校验）
- [x] Dockerfile 一键运行
- [x] CONTRIBUTING（贡献规则：教学决策可解释、题目须双人核对、密钥不入库）
- [x] 课程包架构：新增课程只加 `content/*.json`，不改代码
- [x] 仓库零密钥（已全仓扫描确认）
- [ ] 英文 README 摘要与架构图（发布前补）
- [ ] GitHub Release 打版（v0.3.0 起）
- [ ] 仓库转 Public（由 ark 确认后执行）

## 后续版本（按最终目标排序）

### V0.4 · 编排升级与长期记忆（团队亲手做，学完再动）
- 用 LangGraph 对照重写教学编排（见 learning-path 阶段 3 的对照实验），
  评测不劣于现有状态机才迁移。团队先学完阶段一、二再亲手完成这次迁移——
  这是学习目标本身，不外包、不抢跑
- 对话长期记忆摘要：老师能记住跨节课的上下文，而不只是画像

### V0.5 · RAG 课件知识库
- 课件/教材切片入库，「问老师」回答带出处；支持上传新课件生成新课程包
- 拒答策略：知识库没有的内容明确说没有

### V0.6 · 评测体系（开源可信度的核心）
- 教学案例集进 CI：预设学生作答 → 期望教学动作/误区归因
- 公开评测结果写进 README：判读准确率、案例通过率

### V1.0 · 正式开源发布
- 转 Public + Release v1.0.0 + 中英双语 README + 架构图
- 小范围真实学生试用数据小结（独立测验前后对比）

## 不变的设计红线（任何版本）

1. 掌握判定只认独立测验的证据，不认学生自述、不认对话流畅度
2. 教学决策可解释、可测试；LLM 只做判读与表达，不做流程决策
3. 没把握的内容宁可拒答，不编造公式和出处
4. 学生数据只存本地/自有服务器，密钥永不入库
