## 2. 知识图谱（按先修顺序）

依赖总览：
`U1 器件 → U2 放大原理/工作区 → U3 Q点与偏置 → U4 微变等效 → U5 共射分析 → U6 稳定与失真（回扣 U3） → U7 共集/共基（复用 U4–U5 方法） → U8 多级与频响`

### U1 PN结与三极管结构 / 特性曲线
- **核心概念：** PN结单向导电；NPN/PNP 结构（发射区掺杂最重、基区很薄且掺杂最轻、集电区面积大）；电流分配 IE = IC + IB，放大区 IC = β·IB；共射输入特性（类似二极管，硅管开启约 0.5 V、导通约 0.6–0.7 V）与输出特性族（以 IB 为参变量）；主要参数 β、ICEO、ICM、PCM、U(BR)CEO。
- **常见误区：**
  1. 以为三个极对称、发射极与集电极可互换 — 互换后 β 大幅下降，因为结构不对称。
  2. 把 IC = β·IB 当成任何条件下都成立 — 它只在放大区成立，饱和/截止时不成立。
  3. 读输出特性时分不清横轴 UCE 与纵轴 IC 的因果，把曲线“平台”误读为 IC 由 UCE 决定。
- **先修：** PN结、二极管伏安特性（教材第1章前半）；电路的 KCL。
- **诊断题（原创）：** 硅 NPN 管测得 UBE = 0.3 V、IB ≈ 0、IC ≈ 0，问它最可能在哪个区、为什么？
  - 正确答案：截止区；UBE 小于开启电压，发射结未导通，无基极电流也就无受控集电极电流。
  - 错误揭示：答“放大区，因为接了电源”→ 只看供电不看结偏置（转 U2）；答“饱和区”→ 把“电流为零”与饱和（电流大、UCE 很小）混淆，需回特性曲线图重学。

### U2 放大原理与三种工作状态
- **核心概念：** 放大的本质是小输入控制大输出、能量来自直流电源；三区判据（以 NPN 为例）— 放大：发射结正偏、集电结反偏；饱和：两结正偏，UCE 很小，IC 不再受 IB 线性控制；截止：发射结零/反偏，IB、IC≈0。交流信号“驮载”在直流量上，整周期须留在放大区。
- **常见误区：**
  1. 认为放大是三极管“创造”了能量/信号功率。
  2. 只记发射结正偏就断言放大，漏查集电结必须反偏（两结正偏是饱和）。
  3. 把开关应用（截止/饱和之间切换）与线性放大（始终在放大区）混为一谈。
- **先修：** U1。
- **诊断题（原创）：** NPN 管 UBE = 0.7 V、UCE = 0.2 V，增大 IB 时 IC 几乎不变。问处于何区、还能否作线性放大？
  - 正确答案：饱和区；UCE 已接近饱和压降，IC 受外电路限制，不满足 IC = β·IB，不能线性放大。
  - 错误揭示：答“放大区，因为 UBE=0.7 V 已导通”→ 只查一个结（典型单条件判断）；答“截止区，因为 IC 不变”→ 把“不变”的原因搞反，需对比三区 IC 行为。

### U3 静态工作点 Q 与偏置电路（固定偏置 / 分压式）
- **核心概念：** Q = (IBQ, ICQ, UBEQ, UCEQ)，无信号时在直流通路求；原则“先静态、后动态”。直流通路画法：电容开路。固定偏置：IBQ = (VCC − UBEQ)/RB，简单但 Q 随 β、温度漂移大。分压式（射极偏置）：RB1/RB2 分压定 VB，RE 提供直流负反馈稳定 Q；近似条件是流过分压电阻的电流远大于 IB（工程上常取 5–10 倍）。
- **常见误区：**
  1. 求 Q 时把耦合/旁路电容当短路（那是交流通路画法），导致直流回路全错。
  2. 分压式仍用 IBQ = VCC/RB1 之类固定偏置公式硬套，不先求 VB。
  3. 以为 RE 只是“多余的限流电阻”，看不出它抬高 VE、钳制 IE 的稳定作用；或反过来在交流分析里忘了 CE 把 RE 旁路。
- **先修：** U2；分压、戴维宁等效（电路课）。
- **诊断题（原创）：** 分压式电路 VCC=12 V，RB1=30 kΩ（上）、RB2=10 kΩ（下），RE=1 kΩ，硅管。先不给 β，问能否估算 IEQ、大约多少？
  - 正确答案：能。VB ≈ 12×10/(30+10) = 3 V，VE = 3 − 0.7 = 2.3 V，IEQ ≈ 2.3 mA（这正是分压式“Q 基本与 β 无关”的体现）。
  - 错误揭示：答“缺 β 算不了”→ 仍停在固定偏置思维，没抓住分压式设计目的；先算 IB 再乘 β 且数值差很大 → VB 求错（上下电阻用反），需查分压方向。

### U4 微变等效电路（h 参数 / rbe）
- **核心概念：** 小信号前提：信号小、只在 Q 点附近线性化，只适用于动态分析。h 参数共射模型：输入侧电阻 rbe，输出侧受控电流源 β·ib。rbe 由 Q 点决定（见第4节公式），故“先静态后动态”在此闭环。交流通路画法：直流电压源交流短路（接地）、大电容短路。
- **常见误区：**
  1. 用微变等效电路去求 Q 点（模型里根本没有直流量）。
  2. rbe 当成固定常数（如永远 1 kΩ）套所有题 — 它随 IEQ 变，IEQ 变大 rbe 变小。
  3. 画交流通路时把 VCC 悬空而不是接地，导致 Rc 接法错误、增益符号/数值全错。
- **先修：** U3（rbe 依赖 IEQ）；受控源概念（电路课）。
- **诊断题（原创）：** 同一管子，电路改动后 IEQ 从 1 mA 升到 2 mA（β、rbb′ 不变，取 rbb′=200 Ω、β=50）。rbe 大约如何变？
  - 正确答案：由约 200 + 51×26/1 ≈ 1526 Ω 降到约 200 + 51×26/2 ≈ 863 Ω，即明显减小（增益随后会变，见 U5）。
  - 错误揭示：答“rbe 不变，是器件常数”→ 没理解 rbe 是 Q 点处斜率的线性化结果；答“变大”→ 公式中 IEQ 在分母的关系记反，需回公式推导（VT/IEQ 项）。

### U5 共射放大电路分析（Av、Ri、Ro）
- **核心概念：** 中频段指标：电压放大倍数 Av（负号 = 输出与输入反相）、源电压增益 Avs（计 Rs 分压）、输入电阻 Ri（越大从信号源取流越小）、输出电阻 Ro（越小带负载能力越强）。负载 RL 通过耦合电容与 Rc 并联成交流负载 R′L = Rc // RL。RE 未被旁路时增益公式分母多 (1+β)RE 项、增益下降但稳定性与 Ri 提高。
- **常见误区：**
  1. 算 Av 时只用 Rc、漏掉 RL 并联 — 带载增益被高估。
  2. 把 Ri 直接等同于 rbe — 漏掉 RB1//RB2 的并联（分压式）。
  3. 丢掉负号或解释不了负号来源（ib 流过交流负载使 uo 与 ui 反相）；以及把 Av 与 Avs 混用（有 Rs 时 Avs 绝对值更小）。
- **先修：** U4；并联等效、戴维宁（求 Ro）。
- **诊断题（原创）：** β=100，rbe=1 kΩ，Rc=4 kΩ，RL=4 kΩ，RE 被 CE 完全旁路。求 Av，并说明去掉 RL 后 Av 如何变。
  - 正确答案：R′L = 2 kΩ，Av = −100×2/1 = −200；去掉 RL 后 R′L = 4 kΩ，Av = −400，绝对值变大（但这不等于带载能力变好）。
  - 错误揭示：答 −400（带载时）→ 没并联 RL；答 +200 → 相位概念缺失；答“去载后增益变小”→ 把“空载增益高”与“输出能力”混淆，需回 Ro 定义。

### U6 静态工作点稳定与失真（截止 / 饱和失真）
- **核心概念：** 温度升高 → UBE 减小、β 增大、ICBO 增大，三者都使 ICQ 增大、Q 上移。分压式+RE 的直流负反馈链：T↑→ IC↑→ VE↑→ UBE↓→ IB↓→ IC 回落。失真判据（NPN 共射，输出 uo）：Q 过低 → 输入负半周附近进截止 → **uo 顶部削平（截止失真）**；Q 过高 → 输入正半周附近进饱和 → **uo 底部削平（饱和失真）**；信号过大可双向失真。最大不失真输出幅度由交流负载线与两区边界决定，Q 居中时最大。
  - ⚠️ PNP 管、或观察对象换成 iC 波形时，削顶方向相反/不同 — 教学时必须声明“以 NPN 共射、看 uo 为前提”，这是学生最易死记错位之处。
- **常见误区：**
  1. 只背“顶/底”口诀不带前提，换 PNP 或看 iC 就全错。
  2. 把失真一律归因于“信号太大”，不会通过调 RB（改 Q）区分 Q 不当型失真与幅度型双向失真。
  3. 认为温度只影响 β — 漏掉 UBE 与 ICBO 的变化，且三者方向一致地推高 IC。
- **先修：** U3（调 Q 的手段）；U2（三区边界）。
- **诊断题（原创）：** NPN 共射电路，示波器上 uo 顶部被削平，输入幅度并不大。问是哪种失真、Q 偏高还是偏低、调 RB1（上偏置）向哪个方向试？
  - 正确答案：截止失真，Q 偏低（IBQ/ICQ 太小）；应增大 IBQ，如减小 RB1（或增大 RB2），使 Q 上移。
  - 错误揭示：答“饱和失真”→ 口诀与波形对应反了，多半也没想“顶部削平时 IC 先到零”；答“减小输入信号就行”→ 能掩盖但没治本，且回避 Q 判断，需回负载线图。

### U7 共集（射极跟随器）与共基
- **核心概念：** 判组态看交流通路里哪极是输入/输出回路公共端。共集：基入射出，Av 为正且略小于 1（电压跟随）、电流/功率增益有，Ri 最高、Ro 最低 → 作输入级/输出级/缓冲隔离。共基：射入集出，Av 为正且数值与共射同量级、电流增益略小于 1，Ri 最低、Ro≈Rc，高频特性最好 → 高频/宽带与恒流源负载等场景。共射居中：Av、Ai 都大，Ri/Ro 居中，用作中间增压级。三者对比表是本单元的交付物。
- **常见误区：**
  1. 见 Av≈1 就断言共集“没放大作用、白学” — 忽略它放大电流/功率且阻抗变换价值大。
  2. 按直流接法（哪极接电源）判组态，而不是按交流公共端判 — 集电极经 VCC 交流接地，所以“集电极接电源”恰是共集。
  3. 把共基 Av 写成负号（它同相），或以为 Ri 低就是缺点 — 低 Ri 恰与低阻信号源/高频匹配相关。
- **先修：** U5 的分析套路（同一套微变等效方法迁移）。
- **诊断题（原创）：** 要把高内阻传感器接到低阻负载之间作缓冲，要求电压基本不放大、少取信号源电流、带载稳。选哪种组态、哪两项指标是关键？
  - 正确答案：共集（射极跟随器）；关键是高 Ri（少取流）与低 Ro（带载时输出跌落小），Av≈1 正合“缓冲”需求。
  - 错误揭示：选共射并答“增益最大最好”→ 只盯 Av 单指标，不会按应用选组态；选共基 → Ri 最低与需求正相反，说明三者对比表未建立。

### U8 多级放大与频率响应入门
- **核心概念：** 多级总电压增益 = 各级增益之积（dB 表示时相加），但计算每一级时后级 Ri 是前级的负载，不能用各级空载增益直接相乘。耦合方式入门：阻容耦合（各级 Q 独立、低频受耦合电容限制）、直接耦合（可放大直流/慢变信号，但有零漂与电位匹配问题）。频率响应：中频增益近似恒定；低频下降源于耦合/旁路电容容抗变大，高频下降源于结电容与高频模型（混合 π）；fL、fH 与通频带 BW = fH − fL。多级后通频带变窄（fL 升高、fH 降低），增益带宽积近似守恒的直觉。
- **常见误区：**
  1. 用各级“空载 Av”直接相乘得总增益 — 漏掉级间负载效应，结果系统性偏大。
  2. 以为级数越多带宽越宽或不变 — 实际多级频带变窄。
  3. 把低频下降怪到三极管本身 — 中频模型里管子没问题，低频段是耦合/旁路电容不再能当短路。
- **先修：** U5、U7（单级分析）；RC 电路频率特性（电路课相量法）。
- **诊断题（原创）：** 两级共射，第一级 Av1 = −50（已计入第二级输入电阻作负载），第二级 Av2 = −20。总增益多少、输出与输入同相还是反相？若有人用两级各自空载增益 −80、−30 相乘得 2400，错在哪？
  - 正确答案：总 Av = (−50)×(−20) = +1000，同相（两次反相）；2400 错在空载值没把后级 Ri 当前级负载，重复高估。
  - 错误揭示：答 −1000 → 只乘数值不处理符号/相位累计；认可 2400 → 没建立“级间负载”概念，需回 U5 的 R′L = Rc // R（下一级 Ri）。

## 4. 必须准确的公式（已核对）

核对依据：童诗白/华成英教材目录与智慧教育平台课程表述（来源 #1、#2）、USTC 习题课讲义摘要中的 rbe 表达式（来源 #13）、多所高校 MOOC 大纲（#3、#7–#9）以及 Sedra/Smith 的 gm 体系（#14）。以下均为**中频、小信号、忽略 rce/ro（Early 效应）**条件下的结果，使用时须声明条件。

### 4.1 器件与 Q 点
- 电流关系（放大区）：`IE = IC + IB`，`IC = β·IB`，`IE = (1+β)·IB`
- 热电压（室温约 25–27 °C）：`VT ≈ 26 mV`
- 跨导：`gm = ICQ / VT`；`r_e = 1/gm = VT / IEQ`（T 模型）；`rπ = β / gm`（hybrid-π），且 `rbe = rπ`（h 参数模型与 hybrid-π 在低频下对应）
- 固定偏置：`IBQ = (VCC − UBEQ) / RB`，`ICQ = β·IBQ`，`UCEQ = VCC − ICQ·Rc`（无 RE 时；硅管 UBEQ 常取 0.7 V 估算）
- 分压式偏置（RB2 为下偏置，即基极对地电阻）：
  - `VBQ ≈ VCC · RB2 / (RB1 + RB2)`（近似条件：分压电流 ≫ IBQ）
  - `VEQ = VBQ − UBEQ`，`IEQ ≈ ICQ = VEQ / RE`
  - `UCEQ ≈ VCC − ICQ·Rc − IEQ·RE`

### 4.2 rbe（重点核对）
```
rbe = rbb′ + (1+β) · VT / IEQ  ≈ rbb′ + (1+β) · 26 mV / IEQ
```
- USTC 讲义摘要写作 `rbe = rbb′ + (1+β)VT/IEQ ≈ 200 Ω + (1+β)·26 mV/IEQ`。
- ⚠️ **rbb′ 取值存在来源差异**：不同教材/器件估算取 200 Ω 或 300 Ω 都有出现（如部分讲义写 300 Ω）。公式结构无争议；Agent 题库必须**固定采用一种并在题目中明示**（建议：题目给值时用题给值，未给时按主教材口径并注明），否则同一题会出现两套“标准答案”。

### 4.3 共射（CE）
- RE 被旁路（CE 存在）：`Av = −β(Rc // RL) / rbe = −gm(Rc // RL)`
- RE 未被旁路（无 CE，交流 RE′ 为未旁路部分）：`Av = −β(Rc // RL) / [rbe + (1+β)RE′]`
- 输入电阻（分压式）：`Ri = RB1 // RB2 // rbe`（旁路时）；未旁路时将 rbe 换成 `rbe + (1+β)RE′`
- 输出电阻：`Ro ≈ Rc`（忽略 rce 时）
- 源增益：`Avs = Av · Ri / (Rs + Ri)`

### 4.4 共集（CC，射极跟随器）
- `Av = (1+β)(RE // RL) / [rbe + (1+β)(RE // RL)]`，恒 < 1 且为正（同相）
- `Ri = RB1 // RB2 // [rbe + (1+β)(RE // RL)]`
- `Ro = RE // { [ (Rs // RB1 // RB2) + rbe ] / (1+β) }`（Rs 为信号源内阻；Rs 越小 Ro 越低）

### 4.5 共基（CB）
- `Av = +β(Rc // RL) / rbe ≈ +gm(Rc // RL)`（同相，数值与共射同量级）
- `Ri ≈ RE // [ rbe / (1+β) ]`（很低，约等于 r_e 量级）；`Ro ≈ Rc`

### 4.6 多级与频响
- 总增益：`Av = Av1 · Av2 · …`（每级增益须已计入后级输入电阻为负载）；dB 形式：`Av(dB) = Σ Avi(dB)`
- 通频带：`BW = fH − fL`；多级时 fL 高于单级、fH 低于单级，带宽变窄

### 4.7 失真方向速查（仅限声明前提内使用）
- 前提：**NPN 共射、观察输出电压 uo**。Q 过低 → 截止失真 → uo 顶部削平；Q 过高 → 饱和失真 → uo 底部削平。换 PNP 或改看 iC 波形时结论翻转，判题逻辑里必须带前提条件，不得写成无条件规则。
